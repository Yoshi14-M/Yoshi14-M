# こんにちは、松井 義朗（Yoshiaki Matsui）です 👋
 
PHP / Laravel のバックエンドエンジニアです。
大阪府庁で11年半、課税・医療費助成・予算などの業務に携わり、Excel VBA で作った仕組みで作業が大きく減ったことをきっかけに、エンジニアへの転職を決めました。
COACHTECH で PHP / Laravel・Docker・REST API 設計を学び（2026年12月修了予定）、模擬案件3件と個人開発1件を開発しました。
業務理解をもとに仕様を整理し、テストで品質を確かめながら開発しています。

## 🛠️ 使える技術
 
- **バックエンド**：PHP / Laravel（Fortify・Sanctum）/ REST API
